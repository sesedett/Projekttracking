⚠ Verbindungsfehler

Mögliche Ursachen:

  1. Die Client-ID im Code stimmt nicht (siehe Zeile CLIENT_ID im Script)
  2. Die Azure App hat keine Berechtigung Files.ReadWrite
  3. Der OneDrive-Ordnerpfad existiert nicht
  4. Die Weiterleitungs-URI in Azure stimmt nicht mit dieser URL überein

Einrichtung erforderlich

Trage einmalig deine Azure App-Registrierung ein. Diese Werte werden direkt im HTML gespeichert – du musst das nur einmal tun.

⚠ Du brauchst eine Azure App-Registrierung. Die Schritt-für-Schritt-Anleitung steht weiter unten auf dieser Seite (oder öffne die HTML-Datei in einem Editor).
